# remind-me, 2026-11-01, protocol-subset variant (graded, archived, not promoted)

**Status: archived, not promoted.** `experts/remind-me/` on `main` stays the 2026-10-31
prompt. Graded recall moved 0.70 → 0.74 with precision unchanged at 1.00, but the gain is
disclosed rather than blind, it is offset by a loss on another key in the same case, the
target miss (346-r2 K1) is still 0/5, and the runs cost about 1.7× the tokens. Prompt
variants stop here: #723 replaces them with role + overlay + skill pack (Mill Board #715).

Variant: `experts/remind-me/` at `055f36b`, which adds one failure class to step 2
(**Protocol subset**: for a hand-rolled parser or client, list what the governing spec lets
a conforming peer send, such as framing and terminators, header case and repetition, content
codings and error bodies, and check that each is accepted or refused). The class came from
the baseline's only misses (346's chunked-HTTP keys), so any 346 gain is disclosed, not
blind. Raw run, judge output and isolation check: [2026-11-01-protocol/RUN.md](2026-11-01-protocol/RUN.md).
The prompt change is reverted on this branch. It remains in history at `055f36b`.

Every finding is graded in [2026-11-01-protocol/](2026-11-01-protocol/), following the
2026-10-31 baseline's method: the scorer counts blocking findings only, so a key named only
in a note or an optional improvement scores as missed.

- **346-r1 K2 (up):** runs 2, 3 and 5 make the chunked-response refusal a blocking finding,
  each citing RFC 9112 §7.1. Runs 1 and 4 probed it and saw the error but filed it under
  checks or optional improvements, as every baseline run did. So the class changed the
  ranking in 3 of 5 runs, which is what it was written to do.
- **346-r1 K1 (down):** run 3 found the non-integer `index` fallback, executed it, and then
  put it under optional improvements ("Refusing them would be stricter"). This is the same
  down-ranking failure the class fixed for K2, now on a different key.
- **346-r2 K1 (still missed):** with an explicit instruction to check framing and its
  terminators, all five runs probed `dechunk` (header case, extensions, trailers, truncation
  before the last chunk, a `+` sign on the size). None sent a body that ends at `0\r\n`
  without the trailer section's closing CRLF. The class names the area but not the edge, and
  the runs stop at "trailers are ignored" without asking what ends them.
- **Over-grading:** the same pattern as the baseline. 343-r1 K2 was graded P0 by runs 1, 3, 4
  and 5 ("a stored secret") and P1 by run 2, against the key's P2. 343-r2 run 2 graded K1 P0.
  346-r1 run 5 graded K1 P1. No under-grading.

## Real bugs beyond the keys

Most non-key findings repeat defects the baseline graded, and reuse its executed grades
(each `reason` names the baseline run). New in this run and **still on `main` `15db3280`**:

- **Glued same-kind tokens leak the second body** (P2; 343-r2 run 3). `x npm_<36a>npm_<36b> y`
  becomes `[REDACTED:npm_token]_bbbb…`, and `whsec_` and `sk_live_` behave the same way.
  Executed at `abdd0b76`, `9ef2ec3a` and `main`.
- **README promises connection-string passwords; only URL form is covered** (P2; 343-r1
  run 3). `Server=db;User Id=sa;Pwd=…;` and `host=db user=app password=hunter2` are stored
  unchanged. Executed. README:234 on `main` still makes the claim.
- **Release note overstates card separators** (P2; 343-r2 run 5). Double spaces and dots are
  not accepted. Executed.
- **Cloud capture hook lacks the server's new shapes** (P2; 343-r2 run 4). rusty_mill
  `.claude/hooks/remind-me-capture.py` has no `sk-`, Stripe, GitLab, npm, PyPI, Google or card
  rules, while ADR-0029 says the hook redacts "with the server's secret shapes". Source-traced
  at `libs-2026.10.0` and rusty_mill `main`.
- **Un-superseding a merged member leaves the canonical's evidence and boost** (P2; 344-r1
  run 1). Source-traced: the `clear_superseded` path never touches the canonical.
- **Merge scales a stale `base_weight` snapshot** (P1–P2; 344-r1 runs 2 and 5). Source-traced:
  `merge_one` on `main` still scales `canonical.base_weight` from the `fetch_candidates` snapshot,
  so a value the sync worker applies mid-run is lost.
- **`post_json` tries only the first resolved address** (P2; 346-r1 run 1). With the default
  `localhost` URL it tries `::1`, so a server bound to `127.0.0.1` is never reached. Source-traced
  at `8c7e55a6` and `main` (`.next()` at embedder.rs:367).

Also true at the head but since settled: non-object metadata replaced by `{"evidence":n}` on
merge (344-r1 run 3; `main` now documents this in `keep_evidence`), and ADR-0002 not naming the
openai backend (346-r2 run 1; `main` adds it to the addendum). None filed, per instructions.

## Caveats

- **Author-graded, one grader.** A Claude session graded every finding, with no second reader.
  The 343 probes (`redact.rs` at `abdd0b76`, `9ef2ec3a` and `main` built standalone) were
  executed by the grader and are not committed. The new 344 and 346 grades rest on source
  traces, and each `reason` says which kind it is.
- **Isolation.** The 25 runs shared one `$TMPDIR` with each other and with a concurrent bench.
  RUN.md's trace check found no run reading another case's key fix, but it rests on run order
  and tool-call text, not tool output.
- **Not blind on 346.** The class was written from the baseline's 346 misses.
